#  Интерпретируемая система обнаружения дипфейк-аудио

## Описание проекта

Данный проект представляет собой систему машинного обучения для обнаружения дипфейк-аудио на основе акустических признаков, извлекаемых из речевого сигнала.

В основе системы лежит **классификатор Random Forest** обученный на многоязычных и многодоменных наборах данных, включая датасеты ASVspoof и записи, собранные в реальных условиях (in-the-wild).

Для извлечения акустических признаков используется инструмент **OpenSMILE** с набором признаков **eGeMAPS**. Система выполняет бинарную классификацию аудиозаписей:

- **REAL** - подлинная запись;
- **FAKE** - синтезированная или дипфейк-запись.

---

## Основная идея

Модель анализирует **акустические и косвенные лингвистические характеристики** речи, включая:

- высоту основного тона (Pitch);
- формантную структуру (F1, F2, F3);
- стабильность голоса (джиттер и шиммер);
- спектральные и энергетические характеристики;
- динамику громкости.

Эти признаки позволяют выявлять малозаметные искажения, возникающие при синтезе речи современными генеративными моделями.

---

## Пайплайн

1. Загрузка аудиофайла (WAV/MP3);
2. Извлечение признаков с помощью OpenSMILE (eGeMAPS v02);
3. Приведение признаков к формату, использовавшемуся при обучении модели;
4. Классификация с помощью Random Forest;
5. Оценка вероятностей классов (**REAL / FAKE**);
6. Интерпретация результата на основе наиболее значимых акустических признаков.

---

## Характеристики модели 
- **Модель:** Random Forest Classifier;
- **Признаки:** eGeMAPS (88 признаков);
- **Датасеты для обучения:**
  - ASVspoof2019;
  - ASVspoof5;
  - InTheWild;
  - ODSS;
- **Балансировка классов:** выполнена с использованием `compute_class_weight`.

---

## Веб-интерфейс

Проект включает интерактивный веб-интерфейс, разработанный с использованием **Gradio**, который позволяет:

- загрузить аудиофайл;
- получить результат классификации (**REAL / FAKE**);
- просмотреть уровень уверенности модели;
- ознакомиться с основными акустическими характеристиками, повлиявшими на принятое решение.

## Запуск проекта

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
````

### 2. Запуск приложения

